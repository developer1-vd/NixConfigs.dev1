# NixConfigs.dev1
My nixOS configs

# Dependencies
1. NixOS latest with Plasma 6.6
2. Text Editor (reccomended: kate)
3. A web browser or git
4. Andy Bett's Mountains wallpaper, Nordic Bluish color theme, Sierra dark/alt GNOME/GTK Theme, Breeze App Style, Ant Dark Plasma style, Utterly Round Dark Solid windows decorations, Regular Papirus icons, Nordic cursors, Ocean sounds, and Penrose startup animation. Panel layout is up to you :)

# Install
Clone and move the files to the neccesary files.
